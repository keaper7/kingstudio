# KINGSTUDIO — концепт-сайт

Концепт-проект для портфолио: сайт-витрина фотостудии KINGSTUDIO
(Нальчик, ул. Тарчокова 121). **Не является официальным сайтом студии.**

Собран по той же схеме, что `../publico`: кастомный HTML/CSS без сборки
и зависимостей, GitHub Pages.

## Запуск

```bash
python3 -m http.server 4174
```

## Раскладка

```
index.html            одностраничник, секции 00–07
css/base.css          токены, темы секций, .sec/.btn/.ph/.rv
css/sections.css      секции, лайтбокс, фрейм бронирования
css/responsive.css    брейкпоинты 1080 / 860 / 560
js/main.js            появление при скролле, меню, лайтбокс
img/manifest.py       слоты кадров и параметры кропа
img/process.py        кроп → 400/800/до 1440 → WebP, пишет shots.js
img/shots.js          СГЕНЕРИРОВАН: слоты, ширины и пропорции для srcset
img/raw/              исходники из инстаграма (не в гите)
content/brief.md      исследование: факты, прайс, зоны, правила, источники
```

## Фотографии

Кадры трёх зон выгружены из постов от 20 февраля 2026 и лежат в `img/raw/`
(в репозиторий не попадают — в гит уходят только готовые WebP).

Пересобрать после замены или добавления исходников:

```bash
python3 img/process.py
```

Скрипт кропает по пропорциям из `manifest.py`, пишет WebP в трёх ширинах
и **сам генерирует `img/shots.js`** со списком слотов и реально полученных
ширин. Вёрстка строит `srcset` из него, поэтому ссылки на несуществующие
файлы появиться не могут: нет слота в `shots.js` — на его месте остаётся
`.ph`-заглушка, а не битая картинка.

Ориентации у зон разные (классика и циклорама горизонтальные, дофаминовая
вертикальная) — это заложено в манифест и в вёрстку разделa локаций.

## Полнота относительно их страницы на BookNow

Сверено поблочно: описание студии, услуги и цены, команда с портретами,
подарочный сертификат, FAQ, соцсети, телефон, адрес, реквизиты ИП. Всё это
есть на сайте — разложенное по разделам, а не одним списком.

Аватары фотографов и барельеф студии сняты с их же страницы в оригинальном
разрешении: ссылки на картинки там закодированы base64, внутри лежит путь
к исходнику (800 × 800 вместо отдаваемых 148 px).

## Бронирование

Виджет действующей системы студии встроен во фрейм в секции 06. Проверено,
что `booking.booknow.ru` не отдаёт `X-Frame-Options` и CSP `frame-ancestors`,
то есть встраивание разрешено самим сервисом. Все CTA ведут на якорь
`#booking`; наружу уходит только запасная ссылка под фреймом.
